# Systems Programming Scripts

This repository contains a variety of shell scripts written for Systems Programming coursework.

Scripts demonstrate concepts such as:

- Text processing with 'awk' and 'grep', 
- File and permission handling
- User interaction and I/O
- Scripting in Bourne shell ('sh'), Bash, and C shell

Each script showcases a different aspect of Unix/Linux system utilities and scripting techniques.

> Note: File formats may include '.sh', '.bash', and '.txt' extensions for readability and compatibility.
